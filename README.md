# TinyAir-KD

Official implementation of:

**TinyAir-KD: Bayesian-Optimized Knowledge Distillation for
Energy-Efficient TinyML Air Quality Forecasting**

TinyAir-KD is a Bayesian-optimized hybrid knowledge-distillation
framework for next-hour PM2.5 forecasting on resource-constrained
edge devices. It uses an optimized hybrid LSTM-GRU teacher and a
compact residual MLP student suitable for full-integer INT8
deployment.# TinyAir-KD
